# Results policy

`raw/` contains unique local benchmark runs and is ignored by Git because it includes PPM images and can grow quickly. No run is overwritten. `evidence/` contains versioned copies of real manifests, aggregate tables, telemetry JSON, measured tile metrics, and scheduler traces; it does not contain invented or illustrative measurements. Per-run command records include local absolute paths and remain ignored. MPI-timing pilots are `imbalanced` strong `20260928T003453Z-691d5449`, weak `20260928T003511Z-9bcd77f2`, and `scheduler_stress` strong `20260928T003521Z-97bf7f5a`. The explicit-stall schema is represented by control `20260928T004219Z-c70f7e4f` and treatment `20260928T004233Z-c22bcfc1`. A five-repeat warm-up/manifest check is `20260928T005023Z-61b48527`. Earlier snapshots record implementation iterations, including one before direct-light sampling, and must not be pooled with the current runs. The benchmark harness now writes SHA-256 hashes of the executables into new manifests; earlier manifests do not have that field. `hero.json` records the rendered showcase image. Future plots should be generated from these files and labeled with the source run ID. The final supervised stress result is not yet available.
